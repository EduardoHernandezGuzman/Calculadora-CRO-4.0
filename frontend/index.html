Modelo Bayesiano
El enfoque bayesiano interpreta los resultados en términos de probabilidad directa. En lugar de preguntarse "¿es este resultado estadísticamente significativo?", responde preguntas como: "¿cuál es la probabilidad de que la variante B sea mejor que la A?"
  • No necesitas un tamaño de muestra fijo.
  • Análisis de resultados basado en probabilidad.
  • Decisión más rápida: puedes parar el test cuando desees.

¿Los usuarios pueden convertir una sola vez o más de una vez la métrica a analizar?
  • Conversiones únicas: el usuario puede convertir una sola vez; se analizará mediante la distribución previa Beta, ideal para analizar conversiones (siendo 0 la no conversión y 1 si el usuario ha convertido en la sesión).
  • Conversiones múltiples: con esta opción se analizará mediante la distribución previa Gamma-Poisson, es adecuada para conteos de métricas.
Analizar con conversiones únicas
El usuario puede convertir una sola vez. Se analiza mediante la distribución previa Beta, ideal para conversiones donde 0 = no convierte y 1 = convierte en la sesión.
Analizar con conversiones múltiples
Se analiza mediante la distribución previa Gamma-Poisson, adecuada para conteos de métricas donde un usuario puede convertir más de una vez.
¿Cómo es el tipo de hipótesis que planteas para tu experimento?
  • One-Tailed: se analiza únicamente una diferencia en una dirección específica, ya sea mejora o empeora la métrica objetivo. En caso de seleccionar One-Tailed, en el siguiente paso se indicará si el análisis debe detectar una mejora o un empeoramiento de la métrica.
  • Two-Tailed: se analiza cualquier diferencia, tanto mejora como empeoramiento. Este enfoque evalúa si existe un efecto estadísticamente significativo sin asumir de antemano el sentido del cambio.
One-Tailed
Se analiza únicamente una diferencia en una dirección específica (mejora o empeoramiento). En el siguiente paso elegirás la cola derecha o izquierda.
Two-Tailed
Muestra el IC centrado del uplift relativo. Analiza cualquier diferencia, tanto mejora como empeoramiento. Opción estándar para tests bidireccionales.
¿En qué sentido quieres evaluar la diferencia entre tu versión control y tu versión variante?
  • La variante mejora la métrica (cola derecha): se evalúa si el valor de la métrica en la variante es mayor que en el control, según el criterio definido para el experimento. Ejemplos: compras, añadidos al carrito o visualizaciones de producto.
  • La variante empeora la métrica (cola izquierda): se evalúa si el valor de la métrica en la variante es menor que en el control, según el criterio definido para el experimento. Ejemplos: desinstalaciones de una app, churn rate.

¿Cómo debe ser el formato del CSV?

El archivo CSV debe contener los datos del experimento agregados por día. Incluye las siguientes columnas: día, visitas A, visitas B, conversiones A y conversiones B. La columna día debe usar valores numéricos consecutivos (1, 2, 3…), representando el orden de los días del experimento (no fechas reales).
